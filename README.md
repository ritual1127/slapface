# 👊 얼굴 때리기 (slapface)

사진을 올리면 얼굴을 찰싹 때릴 수 있는 웹 장난감. 의존성 없는 단일 `index.html` 파일 하나로 동작합니다.

## 실행

```bash
# 그냥 브라우저로 열면 됩니다
open index.html
```

빌드도, npm도, 서버도 필요 없습니다.

## 사용법

1. 사진을 드래그하거나 클릭해서 업로드 (JPG · PNG)
2. 자동으로 얼굴 위치를 인식 → **때리러 가기!**
3. 사진을 클릭/터치하면 때립니다. 연타하면 콤보
4. **🩹 치료** 로 초기화, **📸 사진 변경** 으로 다른 사진 선택

## 기능

- **부위 인식** — 눈 / 코 / 입 / 뺨 / 이마를 구분해서 맞은 곳마다 다른 대사와 비명이 나옵니다
- **누적 피해** — 때릴수록 빨개짐 → 멍 → 부어오름 → 피 → 만신창이 순으로 캔버스에 멍이 그려집니다 (0~100%)
- **콤보** — 연타하면 콤보 게이지가 차고, 5콤보마다 문구가 세집니다
- **효과음** — Web Audio API로 실시간 합성. 찰싹 소리(노이즈+저음 thud) + 8종 비명
- **이펙트** — 손 모양, 타격 문구, 별, 피, 링, 화면 흔들림/플래시

## 구현 메모

- **얼굴 인식**: 라이브러리 없이 피부색 픽셀 범위로 얼굴 영역을 잡고, 그 안에서 비율로 눈·코·입 위치를 추정합니다. 인식 실패 시 기본 좌표로 폴백.
- **오브젝트 풀**: 모든 이펙트 DOM은 `FxPool`로 재사용 — 연타해도 DOM이 무한히 늘지 않습니다.
- **스로틀**: 타격 25ms, 소리 30ms, 비명 150ms 간격 제한.
- **멍 렌더링**: 두 장의 캔버스(`multiply` / `overlay` 블렌드)에 방사형 그라디언트 타원을 누적.
- 모바일 대응 — 터치 이벤트, 확대/더블탭 차단.

## ⚠️ 주의

본인 사진 또는 동의를 받은 사진만 사용하세요. 타인의 사진을 무단으로 사용하면 초상권 침해 등 법적 문제가 될 수 있습니다.
